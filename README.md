# Connect-4PyGame
Permainan papan strategi Connect Four 7x6 berbasis Python &amp; Pygame. Susun 4 keping berurutan secara horizontal, vertikal, atau diagonal untuk menang! Tantang Agen AI adaptif yang memadukan Forward Chaining, Minimax Alpha-Beta Pruning, dan Penalaran Bayesian untuk membaca gaya bermainmu secara real-time, lengkap dengan mode uji performa agen.
